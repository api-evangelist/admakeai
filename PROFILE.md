# AdMakeAI

AI ad-creative platform for Meta, Instagram, and TikTok that turns product photos or prompts into finished ad images and UGC-style video ads, batch-generates ad-set variations, researches competitor ads, reads Meta campaign analytics, and drafts campaigns into Meta Ads Manager. Exposes a REST/JSON API, a hosted MCP server (59 tools), and a published agent skill, all bound to one account/credit pool.

- **Provider:** https://admakeai.com/
- **Documentation:** https://admakeai.com/api/docs
- **Base URL:** https://admakeai.com/api/v1
- **Tags:** Advertising, Marketing, AdTech, Generative AI, Image Generation, Video Generation, Meta Ads, Competitive Intelligence, MCP, Agents, Agent Skills
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 90/100

## APIs

- **AdMakeAI REST API** — RPC-style JSON REST API with dot-named methods (e.g. adGeneration.list) covering ad image generation, batch ad sets, Meta analytics (read-only), and Meta campaign draft publishing. Authenticated via x-api-key header. (`https://admakeai.com/api/v1`)
- **AdMakeAI MCP Server** — Hosted, stateless JSON-RPC-over-HTTP MCP server exposing 59 tools for ad generation, batch ad sets, Meta analytics, and Meta draft publishing. Works with Claude Code/Desktop/web, Cursor, VS Code/Copilot, Windsurf, Codex, Gemini CLI, and Cline. Authenticated via x-api-key header. (`https://admakeai.com/api/mcp`)
- **AdMakeAI Agent Skill** — Published SKILL.md that teaches an agent tool selection, credit mechanics, and prompt patterns. Installed via 'npx skills add admakeai/agent-skills'. (`https://admakeai.com/agents`)

> REST base URL (/api/v1), the hosted MCP server (/api/mcp), the agent skill (npx skills add admakeai/agent-skills), and the x-api-key auth model are all directly corroborated by the human-readable /agents page. The MCP install uses 'claude mcp add --transport http admakeai https://admakeai.com/api/mcp --header x-api-key:<key>'. No OpenAPI/AsyncAPI/GraphQL/Postman contract was found publicly; the only machine-readable contract is the self-describing MCP tool list. Read-only API/analytics calls are free; write actions consume credits and never auto-publish.
